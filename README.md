# RH-Modelo Solidário - Banco de Talentos

O **RH-Modelo Solidário** é uma plataforma web desenvolvida como solução de impacto social para o **Instituto Cidadania e Inclusão Digital**. O sistema centraliza o cadastro de currículos, histórico de capacitações e gerenciamento de vagas de emprego, automatizando a triagem de candidatos em situação de vulnerabilidade e facilitando o encaminhamento para o mercado de trabalho regional.

Este projeto faz parte do ciclo de engenharia do **Projeto Integrador Extensionista (PIE)** do curso de Análise e Desenvolvimento de Sistemas da UnimarEAD.

## 📁 Estrutura do Repositório

O repositório está organizado para segmentar as responsabilidades de desenvolvimento e documentação da seguinte forma:

* `/docs`: Documentação técnica do projeto, incluindo o Documento de Visão Consolidado em formato PDF.
* `/backend`: Estrutura destinada à API REST e às regras de negócio da aplicação.
* `/frontend`: Código correspondente à interface do usuário desenvolvida em ambiente SPA.
* `/database`: Scripts de modelagem de dados, diagramas e rotinas de banco de dados.

## 🛠️ Tecnologias Planejadas

* **Front-end:** React / TypeScript / Tailwind CSS
* **Back-end:** Node.js / Express
* **Banco de Dados:** PostgreSQL / Firebase
